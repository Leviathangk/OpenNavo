## 新功能

- 菜单栏监控现在可以在退出 OpenNavo 后继续运行。该功能默认开启，首次会提示一次关闭位置；可在「设置 → 电脑监控」中查看状态。无需打开 App，点击菜单栏项目即可查看读数；风扇信息仅显示，不能在此调节。
- 本地 MCP 现在可以为已列出的应用排队更新，并清理可再生成的缓存；所有操作仍需通过确认窗口，并记录在本地操作记录中。确认窗口还会显示调用方的 Team ID。

## 改进

- 安装、卸载、清理和 Brewfile 恢复等破坏性操作统一使用 OpenNavo 确认窗口：执行前会再次核对计划，「允许」需稍等片刻才能点击，关闭或离开窗口即视为拒绝。
- 清理不会删除超过确认页展示的内容；无法完整测量大小的项目会以「至少」标记并默认不选中。
- 更新提醒只列出页面上可见且新出现的更新。
- 仅用键盘时，可在「允许」按钮获得焦点后按 Command-Return 确认；单独按 Return、空格或 Escape 仍为拒绝。
- 深链接只打开公开网址；安装忙碌和防火墙确认现在会安全失败，不会重试或误放行。

## 修复

- 加强本地 MCP 确认窗口，防止通过页面跳转、重新聚焦或页面崩溃绕过确认，并保留被拒绝请求的操作记录。
- 上报记录被拒或发生重定向后，使用情况上报仍会继续。
- 修正各语言中的 Bundle ID 标签和已移动应用的警告。
