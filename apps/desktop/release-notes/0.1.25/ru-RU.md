## Новое

- Монитор в строке меню теперь может продолжать работу после выхода из OpenNavo. Он включён по умолчанию, а при первом запуске появляется уведомление о том, где его отключить; состояние можно проверить в «Настройки → Мониторинг ресурсов». Нажмите на элемент в строке меню, чтобы увидеть показатели, не открывая приложение. Значения вентиляторов доступны только для просмотра.
- Локальный MCP теперь может ставить в очередь обновления приложений, которые уже отображаются в списке, и очищать восстанавливаемые кеши — только через окно подтверждения и локальный журнал действий. В окне подтверждения также отображается Team ID отправителя.

## Улучшения

- Опасные действия используют окна подтверждения OpenNavo: план повторно проверяется перед выполнением, «Разрешить» становится доступной после короткой задержки, а закрытие окна или переход в другое окно считается отказом.
- Очистка никогда не удаляет больше, чем было показано на экране проверки. Элементы, размер которых не удалось измерить полностью, отображаются невыбранными с пометкой «не менее».
- Уведомления об обновлениях называют только видимые и новые обновления.
- При управлении только с клавиатуры можно подтвердить через Command-Return, когда фокус находится на «Разрешить»; Return, пробел и Escape по-прежнему означают отказ.
- Прямые ссылки открывают только публичные URL; занятые установки и подтверждения брандмауэра теперь безопасно завершаются ошибкой, а не повторяются и не одобряются.

## Исправления

- Окна подтверждения локального MCP защищены от обхода через навигацию, повторный фокус или сбой страницы; отклонённые запросы сохраняются в журнале.
- Отчёт об использовании продолжается после отклонённой записи или перенаправления.
- Исправлены метка Bundle ID и предупреждения о перемещённых приложениях во всех языках.
