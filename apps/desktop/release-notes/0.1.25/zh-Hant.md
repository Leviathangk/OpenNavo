## 新功能

- 選單列監控現在可以在退出 OpenNavo 後繼續執行。該功能預設開啟，首次會提示一次關閉位置；可在「設定 → 電腦監控」中檢視狀態。無需開啟 App，點選選單列專案即可檢視讀數；風扇資訊僅顯示，不能在此調節。
- 本地 MCP 現在可以為已列出的應用排隊更新，並清理可再生成的快取；所有操作仍需透過確認視窗，並記錄在本地操作記錄中。確認視窗還會顯示呼叫方的 Team ID。

## 改進

- 安裝、解除安裝、清理和 Brewfile 恢復等破壞性操作統一使用 OpenNavo 確認視窗：執行前會再次核對計劃，「允許」需稍等片刻才能點選，關閉或離開視窗即視為拒絕。
- 清理不會刪除超過確認頁展示的內容；無法完整測量大小的專案會以「至少」標記並預設不選中。
- 更新提醒只列出頁面上可見且新出現的更新。
- 僅用鍵盤時，可在「允許」按鈕獲得焦點後按 Command-Return 確認；單獨按 Return、空格或 Escape 仍為拒絕。
- 深連結只開啟公開網址；安裝忙碌和防火牆確認現在會安全失敗，不會重試或誤放行。

## 修復

- 加強本地 MCP 確認視窗，防止透過頁面跳轉、重新聚焦或頁面崩潰繞過確認，並保留被拒絕請求的操作記錄。
- 上報記錄被拒或發生重定向後，使用情況上報仍會繼續。
- 修正各語言中的 Bundle ID 標籤和已移動應用的警告。
