## 新機能

- メニューバーのモニターが、OpenNavo を終了した後も動作を続けられるようになりました。既定でオンで、初回にオフにする場所を一度お知らせします。設定 → システムモニタで状態を確認できます。アプリを開かなくても、メニューバーの項目をクリックすると数値を確認できます。ファンの値は閲覧のみです。
- ローカル MCP が、一覧にあるアプリの更新をキューに入れ、再生成可能なキャッシュを削除できるようになりました。いずれも確認ウィンドウとローカル操作履歴を経由します。確認ウィンドウには呼び出し元の Team ID も表示されます。

## 改善

- インストール、アンインストール、クリーンアップ、Brewfile の復元などの破壊的操作は OpenNavo の確認ウィンドウを使用します。実行前に計画を再確認し、「許可」は少し待ってから押せます。ウィンドウを閉じるか離れると拒否になります。
- クリーンアップは確認画面に表示された以上のものを削除しません。サイズを完全に測定できなかった項目は「以上」と表示され、未選択になります。
- 更新通知には、画面に表示され、新しく利用可能になった更新だけが表示されます。
- キーボードのみでも、「許可」にフォーカスがある状態で Command-Return を押して確認できます。Return、Space、Escape だけでは拒否のままです。
- ディープリンクは公開 URL のみを開きます。インストールのビジー状態やファイアウォールの確認は、再試行や誤許可をせず安全に失敗します。

## 修正

- ローカル MCP の確認ウィンドウを強化し、画面遷移、再フォーカス、クラッシュによる回避を防ぐとともに、拒否された要求を操作履歴に残します。
- 記録が拒否されたりリダイレクトされたりしても、使用状況の報告を続けます。
- 各言語の Bundle ID ラベルと、移動したアプリの警告を修正しました。
