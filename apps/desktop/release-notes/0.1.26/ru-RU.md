## Новое

- Очистка теперь может удалять восстанавливаемые кэши, журналы и брошенные загрузки инструментов ИИ-программирования, включая Codex, Claude Code, Cursor, Antigravity, Continue и opencode. Сессии, память и учетные данные остаются.
- В проекте, которым вы еще пользуетесь, файлы инкрементальной сборки можно удалить отдельно. Это только замедлит следующую сборку. Полная пересборка проекта остается отдельным пунктом и сначала не выбрана.
- Хранилища истории ИИ остаются только для чтения. Файлы расшифровок старше 30 дней можно по одному перемещать в Корзину. На проверке видно, сколько сессий попадает в 30, 90, 180 и 365 дней, а также самую раннюю и самую позднюю даты.
- Скачанные веса моделей Ollama, LM Studio, Hugging Face, Jan и GPT4All можно переместить в Корзину. Чаты, наборы данных и локальные индексы документов остаются. Если этот инструмент запущен, его хранилище не трогается. Локальный MCP не может выбрать эти пункты.
- Worktree Git и повторные клоны показываются вместе с занимаемым местом. Связанный worktree удаляется только если Git это принимает, поэтому незафиксированные изменения отклоняются; ветка и основной репозиторий остаются. Повторный клон перемещается в Корзину только когда он чистый, полностью отправлен и без stash. Поврежденный worktree только показывается, удалить его здесь нельзя. Строки сверх предела списка считаются, но не показываются.

## Улучшения

- Проект без правок исходников 30 дней может предложить результат сборки к очистке. Проект с недавними правками считается используемым, поэтому предлагается только меньшая инкрементальная сборка.
- Файлы за последние 7 дней остаются только для чтения. Цель на 7–30 дней предлагается без выбора. Выбранной сразу становится только цель, которую проверка активности признала неиспользуемой. Папка и файлы внутри нее не считаются дважды.

## Исправления

- Каждый кэш Cursor показывается со своим обоснованием.
- Очистка локальных моделей перечисляет только файлы моделей и только если каталог модели существует.
- Перед удалением worktree снова проверяется, что папка все еще принадлежит этому репозиторию.
