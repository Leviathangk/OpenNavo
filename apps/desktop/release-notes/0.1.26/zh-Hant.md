## 新功能

- 清理現在可以刪除 AI 程式設計工具裡可再生成的快取、日誌和未完成的下載，包括 Codex、Claude Code、Cursor、Antigravity、Continue 和 opencode。會話、記憶和憑據會保留。
- 仍在使用的專案裡，可以單獨清理增量構建檔案，這隻會讓下一次構建變慢。整專案重新構建是另一項，預設不選中。
- AI 歷史目錄保持只讀。超過 30 天的會話記錄可以逐個移到垃圾桶。確認頁會按 30、90、180 和 365 天彙總會話數量，並顯示最早和最新的日期。
- Ollama、LM Studio、Hugging Face、Jan 和 GPT4All 已下載的模型權重可以移到垃圾桶。聊天、資料集和本地文件索引會保留。對應工具正在執行時，它的模型目錄會留在原地。本地 MCP 不能選擇這些專案。
- 會列出 Git worktree 和重複克隆及其佔用空間。關聯的 worktree 只有在 Git 接受時才會移除，因此未提交的改動會被拒絕；分支和主倉庫保留。重複克隆只有在工作區乾淨、已全部推送且沒有 stash 時才會移到垃圾桶。損壞的 worktree 只顯示佔用，不能在這裡移除。超出列表上限的條目只計數，不逐條列出。

## 改進

- 30 天內沒有原始碼改動的專案，可以清理它的構建產物。最近仍有改動的專案視為仍在使用，只提供較小的增量構建清理。
- 最近 7 天內的檔案保持只讀。7 到 30 天的目標會列出但不預選。只有活動檢查確認已閒置的目標才會預設選中。資料夾和其中的檔案不會重複計算。

## 修復

- 每個 Cursor 快取都會帶上各自的依據。
- 本地模型清理只列出模型檔案，並且只在模型目錄存在時列出。
- 移除 worktree 前會再次確認該資料夾仍屬於對應倉庫。
