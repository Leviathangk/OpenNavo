## 新機能

- クリーンアップで、Codex、Claude Code、Cursor、Antigravity、Continue、opencode など AI コーディングツールの、再生成できるキャッシュ、ログ、未完了のダウンロードを削除できるようになりました。セッション、メモリ、資格情報は残ります。
- まだ使っているプロジェクトでは、増分ビルドのファイルだけを削除できます。次のビルドが遅くなるだけで、プロジェクト全体の再ビルドは別の項目で、最初は選択されていません。
- AI の履歴ストアは読み取り専用のままです。30 日より古いセッションファイルは、1 件ずつゴミ箱へ移動できます。確認画面では、30 日、90 日、180 日、365 日以内の件数と、最も古い日付、最も新しい日付を表示します。
- Ollama、LM Studio、Hugging Face、Jan、GPT4All にダウンロードしたモデルの重みをゴミ箱へ移動できます。チャット、データセット、ローカルの文書インデックスは残ります。そのツールが起動中のときは、モデルの保存場所はそのまま残します。ローカル MCP からは選択できません。
- Git worktree と重複クローンを、使用容量とともに一覧します。リンクされた worktree は Git が受け入れるときだけ削除されるため、未コミットの変更は拒否され、ブランチとメインリポジトリは残ります。重複クローンは、作業ツリーがきれいで、すべて push 済み、stash がないときだけゴミ箱へ移動します。壊れた worktree は容量だけ表示し、ここから削除できません。一覧の上限を超えた行は件数だけ数え、個別には出しません。

## 改善

- ソースの変更が 30 日間ないプロジェクトは、ビルド出力のクリーンアップを提案できます。最近編集したプロジェクトは使用中とみなし、より小さい増分ビルドだけを提案します。
- 過去 7 日のファイルは読み取り専用のままです。7〜30 日の対象は表示しますが、最初は選択しません。活動チェックで使われていないと確認できた対象だけが最初から選択されます。フォルダとその中のファイルを二重に数えません。

## 修正

- Cursor のキャッシュごとに、それぞれの根拠を表示します。
- ローカルモデルのクリーンアップはモデルファイルだけを一覧し、モデル用ディレクトリがあるときだけ表示します。
- worktree を削除する前に、そのフォルダが今もそのリポジトリのものであることを再確認します。
