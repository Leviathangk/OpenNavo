## 新功能

- 清理现在可以删除 AI 编程工具里可再生成的缓存、日志和未完成的下载，包括 Codex、Claude Code、Cursor、Antigravity、Continue 和 opencode。会话、记忆和凭据会保留。
- 仍在使用的项目里，可以单独清理增量构建文件，这只会让下一次构建变慢。整项目重新构建是另一项，默认不选中。
- AI 历史目录保持只读。超过 30 天的会话记录可以逐个移到废纸篓。确认页会按 30、90、180 和 365 天汇总会话数量，并显示最早和最新的日期。
- Ollama、LM Studio、Hugging Face、Jan 和 GPT4All 已下载的模型权重可以移到废纸篓。聊天、数据集和本地文档索引会保留。对应工具正在运行时，它的模型目录会留在原地。本地 MCP 不能选择这些项目。
- 会列出 Git worktree 和重复克隆及其占用空间。关联的 worktree 只有在 Git 接受时才会移除，因此未提交的改动会被拒绝；分支和主仓库保留。重复克隆只有在工作区干净、已全部推送且没有 stash 时才会移到废纸篓。损坏的 worktree 只显示占用，不能在这里移除。超出列表上限的条目只计数，不逐条列出。

## 改进

- 30 天内没有源码改动的项目，可以清理它的构建产物。最近仍有改动的项目视为仍在使用，只提供较小的增量构建清理。
- 最近 7 天内的文件保持只读。7 到 30 天的目标会列出但不预选。只有活动检查确认已闲置的目标才会默认选中。文件夹和其中的文件不会重复计算。

## 修复

- 每个 Cursor 缓存都会带上各自的依据。
- 本地模型清理只列出模型文件，并且只在模型目录存在时列出。
- 移除 worktree 前会再次确认该文件夹仍属于对应仓库。
