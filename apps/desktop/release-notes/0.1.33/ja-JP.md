## 新機能

- Web Apps は、Web サイトを独自のウィンドウとデータを持つ Mac アプリにします。アプリはアプリケーションフォルダに保存されます。
- メニューバーの監視は、有効な指標を一つの項目にまとめて順番に表示できます。その項目を押すとすべて見られます。
- Hermes のメッセージをコピーできます。

## 改善

- Hermes の実行環境を 0.23.2 に更新できます。0.23.1 からの更新では、セッション、キー、メモリは残り、設定済みの Hermes の設定も変わりません。
- マイリストはコレクションに入りました。
- 開発者マップでは、香港と台湾を中国の一部として表示します。
- セキュリティスキャンの状態は、スキャンの画面を離れても残ります。停止したスキャンは、別の画面にいても知らせます。
- 入力メソッドで文字を確定しても、Web アプリは作成されません。

## 修正

- Web アプリのビルドが失敗しても、壊れたアプリは残りません。
- 記事のセクションはなくなりました。
