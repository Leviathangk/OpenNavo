## Новое

- Веб-приложения превращают сайт в приложение для Mac со своим окном и данными. Приложение сохраняется в папке «Программы».
- Наблюдение в строке меню может показывать все включённые показатели в одном пункте, по очереди. Нажмите пункт, чтобы увидеть их все.
- Сообщение Hermes можно скопировать.

## Улучшения

- Hermes может обновить среду до 0.23.2. Обновление с 0.23.1 сохраняет сеансы, ключи и память и не меняет уже заданные настройки Hermes.
- «Мой список» теперь входит в подборки.
- Карта разработчиков показывает Гонконг и Тайвань как часть Китая.
- Проверка безопасности сохраняет состояние, когда вы уходите со вкладки проверки. Остановка проверки сообщается и на другой вкладке.
- Подтверждение текста методом ввода больше не создаёт веб-приложение.

## Исправления

- Неудачная сборка веб-приложения не оставляет повреждённое приложение.
- Раздел «Статьи» удалён.
