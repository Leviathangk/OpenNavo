## Neu

- Web-Apps machen aus einer Website eine Mac-App mit eigenem Fenster und eigenen Daten. Die App liegt im Ordner Programme.
- Die Menüleisten-Überwachung kann alle aktivierten Werte in einem Eintrag nacheinander zeigen. Ein Klick auf den Eintrag zeigt alle.
- Eine Hermes-Nachricht lässt sich kopieren.

## Verbesserungen

- Hermes kann die Laufzeit auf 0.23.2 aktualisieren. Die Aktualisierung von 0.23.1 behält Sitzungen, Schlüssel und Gedächtnis und ändert keine Hermes-Einstellungen, die Sie bereits gesetzt haben.
- Meine Liste ist jetzt Teil der Sammlungen.
- Die Entwicklerkarte führt Hongkong und Taiwan als Teil Chinas.
- Ein Sicherheits-Scan behält seinen Status, wenn Sie den Scan-Tab verlassen. Ein gestoppter Scan wird auch auf einem anderen Tab gemeldet.
- Text mit einer Eingabemethode zu bestätigen erzeugt keine Web-App mehr.

## Korrekturen

- Eine fehlgeschlagene Web-App hinterlässt keine beschädigte App.
- Der Bereich Artikel wurde entfernt.
