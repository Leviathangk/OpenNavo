## Улучшения

- Полное сканирование безопасности ускорено благодаря двум изолированным процессам и кэшу чистых файлов. Добавлены отображение хода работы и принудительное повторное сканирование.
- Добавлены группировка процессов по приложениям и разбивка загрузки CPU, включая завершённые дочерние процессы и сам OpenNavo.
- Проблемы с подписями объясняются в отдельном окне с доступом к существующему процессу проверки удаления.
- Улучшены синхронизация каталога, подробности ошибок обновления и выбор загрузок для Mac по типу чипа.
- Можно очистить историю завершённых задач, сохранив записи, для которых ещё доступны отмена или откат.
- Добавлены объяснения запросов прав администратора и тексты разрешений macOS на всех шести поддерживаемых языках.

## Известная проблема

- Сбой SQLite SIGBUS, замеченный при предыдущей проверке, пока не удалось достоверно воспроизвести и устранить.
