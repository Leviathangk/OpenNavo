## 新機能

- オプションの送信アプリファイアウォールを追加。アプリ別・宛先別ルール、接続の確認、履歴、ブロックリストに対応します。OpenNavo で有効にし、案内に従って macOS のシステム拡張とネットワークフィルタを承認してください。
- 防火壁の操作と説明を全6言語で提供します。拡張に接続できない場合、状態と再起動の必要性を表示します。

## 改善

- メニューバーパネルがメインウインドウを前面に出さずに開き、安定して閉じるよう改善しました。
- App Store のアカウント状態の説明を改善し、ダウンロードヘルパーの欠落を明示します。
- スキャン中も起動項目の切り替えに応答し、古いスキャン結果による変更の取り消しを防ぎます。
- 使用中の SQLite ファイルとその別名をセキュリティスキャンから保護し、データベースロックを保持します。
- ウェブサイトのセキュリティ紹介を拡充。カタログの更新時期ルールだけで一時停止したアプリも、条件を満たせば検索インデックスの対象になります。

## ファイアウォールの制限

- 送信 TCP・UDP 接続を制御します。アプリが利用できない場合や確認がタイムアウトした場合、不明な接続は許可されます。障害時にすべて遮断する境界ではありません。
- ドメインルールには macOS が提供するホスト名が必要です。ホスト名がない接続には IP、ポート、アプリのルールを適用できます。

## 既知の問題

- 以前の検証で SQLite SIGBUS クラッシュが発生しました。本版にはデータベースロック保護と回帰テストを追加していますが、元のクラッシュの確実な再現と解決には至っていません。
