## Nouveautés

- Hermes peut afficher des images, de la vidéo, de l’audio et des fichiers dans une réponse. Vous pouvez joindre des fichiers à un message.
- Hermes peut vous prévenir quand une réponse se termine ou échoue alors que sa fenêtre est en arrière-plan. Cliquer sur la notification ouvre cette conversation. Les notifications peuvent être désactivées dans les réglages de Hermes.

## Améliorations

- La carte des développeurs liste les développeurs par pays.
- La mise à jour de l’environnement Hermes local indique que la mise à jour est en cours.
- Chaque profil Hermes garde sa propre liste de modèles, donc les modèles d’un autre profil ne remplacent pas celle que vous modifiez.
- Un message envoyé pendant que Hermes répond encore reste dans cette conversation. Il est conservé si vous changez de profil, arrêtez la réponse ou si l’environnement se reconnecte.
- Confirmer du texte avec une méthode de saisie n’envoie plus le message.

## Corrections

- Cliquer sur une notification Hermes rouvre ce profil lorsque sa fenêtre était fermée.
- Une connexion expirée au panneau Hermes est reconnue, pour que vous puissiez vous reconnecter.
