## 新機能

- Hermes の返信に画像、動画、音声、ファイルを表示できます。メッセージに添付ファイルを追加することもできます。
- Hermes のウィンドウが背面にあるとき、返信の完了または失敗でシステム通知が出ます。通知を押すとその会話を開きます。通知は Hermes の設定でオフにできます。

## 改善

- 開発者マップは開発者を国ごとに一覧します。
- ローカルの Hermes 実行環境を更新するとき、更新中であることが表示されます。
- 各 Hermes Profile は自分のモデル一覧を保持するので、編集中の一覧が別の Profile のモデルで置き換わりません。
- Hermes がまだ返信しているあいだに送ったメッセージは、その会話に残ります。Profile を切り替えても、返信を停止しても、実行環境が再接続しても保持されます。
- 入力メソッドで文字を確定しても、メッセージは送信されません。

## 修正

- Hermes の通知を押すと、その Profile のウィンドウが閉じていても再び開きます。
- Hermes Panel のサインイン期限が切れているときは、それを認識するので再度サインインできます。
