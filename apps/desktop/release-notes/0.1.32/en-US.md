## New

- Hermes can show images, video, audio and files in a reply. You can attach files to a message.
- Hermes can notify you when a reply finishes or fails while its window is in the background. Clicking the notification opens that conversation. Notifications can be turned off in Hermes settings.

## Improvements

- The developer map lists developers by country.
- Updating the local Hermes runtime shows that the update is in progress.
- Each Hermes profile keeps its own model list, so another profile's models do not replace the one you are editing.
- A message you send while Hermes is still replying stays with that conversation. It is kept if you switch profiles, stop the reply, or the runtime reconnects.
- Confirming text with an input method no longer sends the message.

## Fixes

- Clicking a Hermes notification opens that profile again when its window was closed.
- An expired Hermes panel sign-in is recognized, so you can sign in again.
