## 新功能

- Hermes 的回覆可以顯示圖片、影片、音訊和檔案。你也可以在訊息裡新增附件。
- Hermes 視窗在背景時，回覆完成或失敗會發出系統通知。點通知會開啟那次對話。通知可以在 Hermes 設定裡關閉。

## 改進

- 開發者地圖按國家列出開發者。
- 更新本地 Hermes 執行環境時會顯示正在更新。
- 每個 Hermes Profile 保留自己的模型列表，編輯時不會被另一個 Profile 的模型蓋掉。
- Hermes 還在回覆時發出的訊息會留在那次對話裡。切換 Profile、停止回覆或執行環境重新連線後，這條訊息仍會保留。
- 用輸入法確認文字時，不會把訊息發出去。

## 修復

- 點 Hermes 通知時，如果那個 Profile 的視窗已關閉，會重新開啟。
- Hermes Panel 的登入過期後會被認出來，你可以重新登入。
