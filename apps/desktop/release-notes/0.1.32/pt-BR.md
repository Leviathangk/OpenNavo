## Novidades

- O Hermes pode mostrar imagens, vídeo, áudio e arquivos em uma resposta. Você pode anexar arquivos a uma mensagem.
- O Hermes pode avisar quando uma resposta termina ou falha enquanto a janela está em segundo plano. Clicar na notificação abre essa conversa. As notificações podem ser desligadas nos ajustes do Hermes.

## Melhorias

- O mapa de desenvolvedores lista os desenvolvedores por país.
- Atualizar o runtime local do Hermes mostra que a atualização está em andamento.
- Cada perfil do Hermes mantém a própria lista de modelos, então os modelos de outro perfil não substituem a lista que você está editando.
- Uma mensagem enviada enquanto o Hermes ainda responde permanece nessa conversa. Ela é mantida se você trocar de perfil, interromper a resposta ou o runtime reconectar.
- Confirmar texto com um método de entrada não envia mais a mensagem.

## Correções

- Clicar em uma notificação do Hermes abre de novo esse perfil quando a janela estava fechada.
- Um login expirado no painel do Hermes é reconhecido, para que você possa entrar de novo.
