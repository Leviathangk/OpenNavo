## Neu

- Hermes kann in einer Antwort Bilder, Video, Audio und Dateien zeigen. Sie können Dateien an eine Nachricht anhängen.
- Hermes kann benachrichtigen, wenn eine Antwort endet oder fehlschlägt, während sein Fenster im Hintergrund ist. Ein Klick auf die Mitteilung öffnet diese Unterhaltung. Mitteilungen lassen sich in den Hermes-Einstellungen ausschalten.

## Verbesserungen

- Die Entwicklerkarte listet Entwickler nach Land.
- Beim Aktualisieren der lokalen Hermes-Laufzeit wird angezeigt, dass die Aktualisierung läuft.
- Jedes Hermes-Profil behält seine eigene Modellliste, sodass die Modelle eines anderen Profils nicht die Liste ersetzen, die Sie bearbeiten.
- Eine Nachricht, die Sie senden, während Hermes noch antwortet, bleibt bei dieser Unterhaltung. Sie bleibt erhalten, wenn Sie das Profil wechseln, die Antwort stoppen oder die Laufzeit sich neu verbindet.
- Text mit einer Eingabemethode zu bestätigen sendet die Nachricht nicht mehr.

## Korrekturen

- Ein Klick auf eine Hermes-Mitteilung öffnet dieses Profil wieder, wenn sein Fenster geschlossen war.
- Eine abgelaufene Anmeldung am Hermes-Panel wird erkannt, sodass Sie sich erneut anmelden können.
