## Novità

- Hermes può mostrare immagini, video, audio e file in una risposta. Puoi allegare file a un messaggio.
- Hermes può avvisarti quando una risposta finisce o fallisce mentre la sua finestra è in secondo piano. Facendo clic sulla notifica si apre quella conversazione. Le notifiche si possono disattivare nelle impostazioni di Hermes.

## Miglioramenti

- La mappa degli sviluppatori elenca gli sviluppatori per paese.
- L’aggiornamento dell’ambiente Hermes locale mostra che l’aggiornamento è in corso.
- Ogni profilo Hermes tiene il proprio elenco di modelli, quindi i modelli di un altro profilo non sostituiscono quello che stai modificando.
- Un messaggio inviato mentre Hermes sta ancora rispondendo resta in quella conversazione. Viene conservato se cambi profilo, interrompi la risposta o l’ambiente si riconnette.
- Confermare il testo con un metodo di input non invia più il messaggio.

## Correzioni

- Facendo clic su una notifica di Hermes si riapre quel profilo se la sua finestra era chiusa.
- Un accesso scaduto al pannello Hermes viene riconosciuto, così puoi accedere di nuovo.
