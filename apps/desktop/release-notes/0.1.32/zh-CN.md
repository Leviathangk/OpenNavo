## 新功能

- Hermes 的回复可以显示图片、视频、音频和文件。你也可以在消息里添加附件。
- Hermes 窗口在后台时，回复完成或失败会发出系统通知。点通知会打开那次对话。通知可以在 Hermes 设置里关闭。

## 改进

- 开发者地图按国家列出开发者。
- 更新本地 Hermes 运行环境时会显示正在更新。
- 每个 Hermes Profile 保留自己的模型列表，编辑时不会被另一个 Profile 的模型盖掉。
- Hermes 还在回复时发出的消息会留在那次对话里。切换 Profile、停止回复或运行环境重新连接后，这条消息仍会保留。
- 用输入法确认文字时，不会把消息发出去。

## 修复

- 点 Hermes 通知时，如果那个 Profile 的窗口已关闭，会重新打开。
- Hermes Panel 的登录过期后会被认出来，你可以重新登录。
