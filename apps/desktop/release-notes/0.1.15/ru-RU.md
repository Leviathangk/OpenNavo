## Улучшения

- Добавлена необязательная анонимная статистика использования работающих установок Mac, включая фоновую работу. По умолчанию она отключена и включается в настройках; отправляются только случайный идентификатор, время, платформа, версия приложения и язык. Отключение удаляет локальный идентификатор и неотправленные записи.
- При включённой автоматической проверке обновления OpenNavo проверяются каждый час, а не только до первой успешной проверки за день.
- Исправлена ситуация, когда обновление сведений Homebrew при запуске препятствовало проверкам по расписанию для выбранных источников обновлений.

## Известная проблема

- Сбой SQLite SIGBUS, замеченный при предыдущей проверке, пока не удалось достоверно воспроизвести и устранить.
