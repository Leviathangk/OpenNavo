## Miglioramenti

- Ora è possibile riaprire OpenNavo direttamente dalla richiesta di autorizzazione quando le autorizzazioni sono pronte, così le nuove autorizzazioni di macOS diventano effettive senza blocchi.
- I link che aprono OpenNavo non vengono più persi quando OpenNavo si riapre per applicare le nuove autorizzazioni.
- Gli articoli e le schede delle release non mostrano più etichette di traduzione.
- Ora funzionano correttamente l’installazione, l’aggiornamento e la disinstallazione delle app dei tap di Homebrew che nel catalogo compaiono con un nome diverso.
