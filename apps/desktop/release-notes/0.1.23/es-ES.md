## Mejoras

- Vuelve a abrir OpenNavo directamente desde el aviso de permisos cuando los permisos estén listos, para que los nuevos permisos de macOS se apliquen sin que la aplicación se quede bloqueada.
- Los enlaces que abren OpenNavo mientras se está reiniciando ya no se pierden.
- Los artículos y las tarjetas de lanzamiento ya no muestran etiquetas de traducción.
- Ahora se pueden instalar desde el catálogo aplicaciones de más taps de Homebrew, incluidas las que tienen versiones para Apple Silicon e Intel.
