## Улучшения

- После подготовки разрешений OpenNavo можно снова открыть прямо из запроса разрешений, чтобы новые разрешения macOS вступили в силу без зависания.
- Ссылки, открывающие OpenNavo, больше не теряются, когда он повторно открывается для применения новых разрешений.
- В статьях и карточках релизов больше не отображаются метки перевода.
- Теперь корректно работают установка, обновление и удаление приложений из tap-репозиториев Homebrew, которые отображаются в каталоге под другим именем.
