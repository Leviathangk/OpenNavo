## Улучшения

- После подготовки разрешений OpenNavo можно снова открыть прямо из запроса разрешений, чтобы новые разрешения macOS вступили в силу без зависания.
- Ссылки, открывающие OpenNavo во время его перезапуска, больше не теряются.
- В статьях и карточках релизов больше не отображаются метки перевода.
- Теперь из каталога можно устанавливать приложения из большего числа tap-репозиториев Homebrew, включая приложения с вариантами для Apple Silicon и Intel.
