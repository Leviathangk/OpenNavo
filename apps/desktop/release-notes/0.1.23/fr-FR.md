## Améliorations

- Permet de rouvrir OpenNavo directement depuis la demande d’autorisation une fois les autorisations prêtes, afin que les nouvelles autorisations macOS prennent effet sans blocage.
- Les liens qui ouvrent OpenNavo ne sont plus perdus lorsqu’il se rouvre pour appliquer de nouvelles autorisations.
- Les articles et les cartes de version n’affichent plus d’étiquettes de traduction.
- L’installation, la mise à jour et la désinstallation des applications de taps Homebrew qui apparaissent dans le catalogue sous un autre nom fonctionnent désormais correctement.
