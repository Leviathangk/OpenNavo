## Améliorations

- Permet de rouvrir OpenNavo directement depuis la demande d’autorisation une fois les autorisations prêtes, afin que les nouvelles autorisations macOS prennent effet sans blocage.
- Les liens qui ouvrent OpenNavo pendant son redémarrage ne sont plus perdus.
- Les articles et les cartes de version n’affichent plus d’étiquettes de traduction.
- Les applications provenant d’un plus grand nombre de taps Homebrew, y compris celles qui proposent des versions Apple Silicon et Intel, peuvent désormais être installées depuis le catalogue.
