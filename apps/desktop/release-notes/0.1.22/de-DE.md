## Verbesserungen

- Unterstützte Updates unsignierter Apps und weitere Prüfhinweise lassen sich mit ausdrücklicher Zustimmung für das jeweilige Update bestätigen.
- Unterstützte Apps können über das Menü installierter Apps erneut installiert werden; dieselbe oder eine ältere Version erfordert eine Bestätigung.
- Verständlichere Update-Fehler bei weiterhin sicheren Wiederholungen, Integritätsprüfungen und Rollbacks.
