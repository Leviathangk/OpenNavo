## New features

- Inspect app security findings, scan downloads with an independent ClamAV engine, and manage supported startup items.
- Discover and manage Mac App Store apps through the native Store integration. Downloads and installations depend on your App Store account and macOS support.
- Check for and install supported native app updates from Sparkle, Electron, GitHub, and curated vendor sources, with identity verification and rollback support where available.
- Browse developer-download apps alongside Homebrew apps, with source-aware details and download links across the desktop app and website.

## Improvements

- Add matching catalog and update-source support to the server and MCP, with interface text in all six supported languages.
- Improve multilingual page titles, descriptions, and canonical URLs on the website.

## Open-source distribution

- OpenNavo's own source now uses GPL-3.0-only. Third-party components retain their licenses and notices.
- Include the corresponding source archive for the bundled ClamAV engine with this release.
