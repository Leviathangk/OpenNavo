## New

- Installed apps now say when an app is built with Electron, and how sure that identification is.

## Improvements

- Popular apps change with the day. The desktop and the website show the same daily set.
- The menu-bar network view lists the processes using the network. Disk and network lists stay in a loading state until the first measurement is ready.

## Fixes

- Selecting many cleanup items no longer freezes the checkboxes.
- A path with a trailing slash is counted once, the same as the path without it.
